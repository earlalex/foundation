Sovereign Learning FAQ

Do I need Webpack or build tools to complete this course? ▼

Absolutely not! Our philosophy is entirely "Zero-Build". We build and program natively inside the browser using standard vanilla ES Module imports, saving time and removing compiler dependencies entirely.

Is my student learning progress synced across devices? ▼

Yes! If you are signed in, your lesson progress is automatically synchronized in real-time to Firestore. If you are browsing anonymously, progress is safely cached inside LocalStorage on your machine.

Are there any prerequisites? ▼

A basic working knowledge of Javascript is helpful, but we guide you step-by-step from core building blocks up to designing advanced API integrations with Stripe and Wise.
