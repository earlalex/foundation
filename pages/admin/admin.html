Integration Setup Guide & Service Keys

Follow these instructions to acquire and set up the third-party API configurations for Foundation:

  • Firebase / Firestore: Visit the Firebase Console. Create a project, navigate to Project Settings, find your Web App configuration block, and copy the apiKey and projectId. Ensure Cloud Firestore and Firebase Authentication (Google provider) are active.
  • Google OAuth Client: Navigate to the Google Cloud Console. Create OAuth 2.0 Credentials, configure scopes for Calendar, Contacts, Gmail, Search Console, and Drive. Add your base domain to the Authorized JavaScript Origins.
  • Google AI Studio Key: Go to the Google AI Studio Console to generate a free API key. This enables Google Gemini 2.5 Flash routing with zero-cost tokens!
  • OpenAI Key: Go to the OpenAI Developer Dashboard to fetch an API Key for gpt-4o-mini low-cost completion.
  • Stripe Integration: Go to Stripe Dashboard. Copy your Secret Key (API tab). Create a monthly subscription product under Products to generate a Price ID (e.g. price_1234...) and configure the environment variables or settings here.
  • VirusTotal API: Register at VirusTotal. Retrieve your free API key from your profile dropdown and insert it under Cloudflare Pages environment variables as VIRUSTOTAL_API_KEY.
  • Google Analytics (GA4) & Looker: Create a web property in Google Analytics to get a Property ID. In Looker Studio, build a report connected to GA4, click Share -> Embed Report, check "Enable Embedding", and copy the source iframe URL to embed it into the Site & Brand tab.

AI Chatbot & Voice Telephony Setup Guide

Follow these steps to wire up the zero-build chatbot widget and messaging webhooks:

  • OpenAI Setup: Visit the OpenAI Dashboard to retrieve an API Key. Note: Cloudflare Edge endpoints will use gpt-4o-mini for highly performant, ultra low-cost completions. If a GEMINI_API_KEY is bound in Cloudflare Secrets, the endpoints will automatically route through Gemini 2.5 Flash at zero token costs!
  • SMS Webhook (Telnyx / Twilio):
    • Telnyx: Point your inbound messages webhook to https://yourdomain.com/api/sms-webhook. Ensure TELNYX_API_KEY and TELNYX_PHONE_NUMBER are set.
    • Twilio: Point your phone number webhook to https://yourdomain.com/api/sms-webhook. Ensure TWILIO_ACCOUNT_SID, TWILIO_AUTH_TOKEN, and TWILIO_PHONE_NUMBER are set in Cloudflare secrets.
  • Voice Telephony Webhook: Set your voice platform call routing webhook (Vapi.ai, Telnyx, or Twilio) to https://yourdomain.com/api/voice-webhook. It responds with valid TwiML/TeXML instructions dynamic voice dialog.
  • Frontend Web Widget: The chatbot widget automatically mounts on the lower-right corner of the site. You can toggle its visibility on/off using the "Chatbot Enabled" switch below.
